## Anthropic — Claude Fable 5.1 / Claude Mythos 5.1 (Sept 1, 2026)
Same underlying model shipped under two safeguard regimes: Fable 5.1 (general availability) and Mythos 5.1 (restricted to vetted cybersecurity/life-sciences users).
- Good for: large, ambitious coding projects spanning an entire codebase, code review, performance work, multi-day autonomous coding sessions (writes its own tests, uses vision to check output against goals).

- Benchmark: 52.6% on Terminal-Bench-Science 0.1 (vs 24.7% for Fable 5, 29.0% for Opus 5).
