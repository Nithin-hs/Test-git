# New AI model releases: daily report for 2026-11-16

This covers about Nov 4 to 16, 2026. Most of these facts come from news sites and release trackers, not from the AI labs. Benchmark numbers are the companies' own claims.

## Highlights

| Model | Company | Date | Type | Open weights? | What it's good for |
|---|---|---|---|---|---|
| **Qwen4-Max-Preview** | Alibaba (China) | Nov 11 (preview until Nov 25) | Text + image + video in, text out. 1M-token context | No (API only) | Coding agents and long multi-step agent tasks. Deep reasoning, tool calling. No benchmarks or pricing yet |
| **ERNIE 5.5 Flash Preview** | Baidu (China) | Nov 11 (base model Nov 5) | Text LLM. 280B MoE, 14B active, 1M context | Planned (Apache 2.0) | Cheap, fast, long-context general model. API on Baidu Qianfan |
| **Claude Fable 5.2** (+ Mythos 5.2) | Anthropic (USA) | Nov 9 | Text + vision LLM. 1M context | No | Long coding and research tasks. About 30% faster than 5.1, 20% cheaper (about $8/$40 per M tokens), new Fast mode. Mythos 5.2 has fewer safeguards and is only for vetted organizations |
| **Muse Ember 1.0** | Meta (USA) | Nov 9–10 | Multimodal in (text, image, video, audio, PDF), text out. 1M context | No (Meta Model API) | Very cheap ($0.10/$0.50 per M tokens) model for repeated agent work: tool calls, routing, extraction, coding subtasks, long documents. Strong on legal and finance tasks |
| **Gemini 4 Carbon** (wider rollout) | Google DeepMind (USA) | Announced Oct 28, wider release in Nov | Frontier LLM | No | Long agentic work in engineering, cybersecurity and science. $2/$10 per M tokens. There is also a separate cyber-defense version |
| **Gemini 4 "Hydrogen"** | Google (USA) | Reported Nov 12–13 | Probably the Flash tier | No | Reported to be very fast, for example for 3D and voxel scene generation. **Unconfirmed codename.** Google has not made an official announcement |
| **GPT Image 2.6 Flare / Sunburst** | OpenAI (USA) | Nov 4 | Image generation and editing | No | Flare is the fast, default choice for social posts, product images and prototypes. Sunburst is for quality: dense layouts, text-heavy images, consistent edits. In ChatGPT, Codex and the API |
| **MiniMax H3-Image** | MiniMax (China) | Nov 10 | Image generation and editing, native 4K | Yes (community license with restrictions) | 4K images in about 10–20 seconds, up to 16 reference images. Can run on one RTX 3090 |
| **Scribe v3 / Scribe v3 Live** | ElevenLabs (USA/UK) | Nov 10 | Speech-to-text | No | Transcription in 102 languages. 27% fewer word errors than v2, and Live adds real-time speaker diarization. $0.20 and $0.22 per hour |

## Quick take
- **Coding and agents:** Claude Fable 5.2, Qwen4-Max-Preview, Gemini 4 Carbon.
- **Cheap, high-volume agent work:** Meta Muse Ember 1.0, ERNIE 5.5 Flash.
- **Images:** GPT Image 2.6 (Flare for speed, Sunburst for detail), MiniMax H3-Image (open weights, 4K).
- **Speech:** ElevenLabs Scribe v3.
- **Open-weight LLMs:** none confirmed this week. ERNIE 5.5 Flash weights are promised soon.
