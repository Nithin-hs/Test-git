# AI Model Releases — 2026-09-16

Daily roundup of new AI model releases from around the world, and what each one is best used for.

No brand-new frontier model launched in the last few days — the newest is still Sakana AI's Fugu Ultra v2.0 from Sept 11. Below is the current state of the field: everything released so far this month that's still relevant, plus the one item that changed today (DeepSeek's traffic cutover).

## OpenAI — GPT-6 Astra (Sept 3–4)
OpenAI's new flagship, rolled out first to approved cybersecurity-program users on Sept 3 with general availability the next day. It's OpenAI's first model to hit the "Critical" cybersecurity capability level under its Preparedness Framework.
- **Good for:** advanced computer use (filling forms, updating CRMs, browsing/research), software engineering, and scientific/professional work — state-of-the-art across all of these per OpenAI, with a 1.05M-token API context window. Available in ChatGPT Plus/Pro/Business/Enterprise and via the OpenAI API and AWS. Pricier than its predecessor at $10/$50 per M input/output tokens.

## OpenAI — GPT Image 2.5 Flare & Sunburst (Sept 8)
An image-generation refresh alongside Astra. Flare is the fast, default tier; Sunburst is the higher-fidelity sibling.
- **Good for:** everyday high-quality image generation and iterative editing — Flare matches or beats GPT-Image-2 quality at ~50% lower latency, keeps people/products recognizable across edits, and changes only the part of an image an edit targets. Adds Sketch (rough-layout reference) and Templates (posters, merch, product photos) in ChatGPT.

## Google — Gemini 3.8 Flash & Gemini 3.8 Flash Cyber (Sept 2)
Released three weeks after 3.7 Flash, for Google AI Pro/Ultra subscribers; the Cyber variant is limited-access via Google Fairwind for governments/trusted partners.
- **Good for:** software engineering and agentic, multi-step reasoning — on DeepSWE v1.1 it beats most larger frontier models at solving engineering problems end-to-end for a fraction of the cost. The Cyber variant is tuned for vulnerability patching. Pricing: $0.75/$3.75 per M input/output tokens.

## Anthropic — Claude Fable 5.1 & Claude Mythos 5.1 (Sept 1)
Same underlying model, two safeguard tiers: Fable 5.1 is generally available, Mythos 5.1 is gated to trusted-access programs (cybersecurity, life sciences).
- **Good for:** ambitious, codebase-spanning coding work, code review, and multi-day autonomous sessions; also complex multi-stage knowledge work handed off with minimal oversight. ~25% cheaper than Fable 5 for typical workloads (up to 45% for agentic work) thanks to a 75% cut to cache-read pricing.

## Meta — Muse Spark 1.3 (Sept 2)
Multimodal agentic reasoning model update from Meta AI, available at the same price as 1.2.
- **Good for:** longer-horizon, multi-workflow agentic coding sessions — it asks clarifying questions, flags when stuck, and confirms before consequential actions instead of hallucinating outcomes. Uses ~20% fewer tool calls and ~25% fewer tokens than 1.2, with a cleaner, less verbose coding style.

## DeepSeek — DeepSeek-V4.1-Flash (Sept 10, now the default — Sept 14)
Open-weight (MIT license) multimodal Mixture-of-Experts model: a 552B-parameter backbone on a new causal encoder-decoder design (8B active params on input, 16B on output), up to a 1M-token context, plus a separate 196B-parameter sparse "Engram" memory component. As of Sept 14, 04:00 UTC, every `deepseek-v4-pro` API request is now served by V4.1 Flash.
- **Good for:** high-throughput, low-latency multimodal (text + native image understanding) work and long-context document/codebase tasks — DeepSeek reports it outperforming its own larger V4-Pro on cost, speed, and latency, with off-peak pricing as low as $0.003 per M cached input tokens.

## Sakana AI — Fugu Max & Fugu Ultra v2.0 (Sept 11)
Not single models but *orchestrators* — one OpenAI-compatible API call that Fugu routes across a pool of underlying models and stitches into one answer. Fugu Ultra v2.0 is the capability-first tier; its model pool excludes Claude Fable 5/5.1 and GPT-6 Astra, which Sakana cites as proof its scores don't depend on any single proprietary frontier model.
- **Good for:** teams wanting top-tier multi-model performance without manually routing between providers — Fugu Ultra v2 leads or ties on 5 of 8 benchmarks (incl. DeepSWE, Chartography, Toolathon). 1M-token context, $5/$30 per M input/output tokens; migration from earlier Fugu versions is a one-line parameter change.

## Notable trend
The frontier-release wave that opened September (Sept 1–11, seven providers, eleven models) has cooled into an integration phase: no new frontier model launched Sept 12–16, and the main news is DeepSeek folding its V4-Pro traffic into the cheaper V4.1 Flash. Expect the next wave once one of the labs above ships a direct answer to GPT-6 Astra or Fugu Ultra v2.0.
